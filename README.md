# NutriLens AI

NutriLens AI adalah aplikasi pendukung keputusan nutrisi personal yang membantu pengguna memahami informasi makanan dan membandingkan trade-off sesuai prioritasnya. Dokumen ini menjadi titik masuk; sebelum development, baca aturan kerja dan dokumen konteks berikut.

## Dokumentasi Proyek

- [AGENTS.md](AGENTS.md) — aturan kerja agent dan konteks proyek.
- [CHANGELOG.md](CHANGELOG.md) — catatan perubahan penting proyek, termasuk fitur, perbaikan, perubahan kontrak, dan keamanan.
- [Ringkasan brainstorming (SUMMARY)](docs/SUMMARY.md) — sumber konteks produk utama, termasuk alur, konsep Nutrition Profile, ML, sumber nutrisi, roadmap, dan pembaruan terbaru.
- [Product Requirements Document (PRD)](docs/PRD.md) — masalah, sasaran, pengguna, dan ruang lingkup produk.
- [Functional Requirements Document (FRD)](docs/FRD.md) — kebutuhan fungsional dan kriteria penerimaan.
- [Rancangan UI/UX](docs/DESIGN.md) — alur layar, komponen, state, dan arahan desain.
- [Register keputusan](docs/DECISIONS.md) — keputusan yang ditegaskan, rekomendasi, konflik, serta hal terbuka.
- [Arsitektur](docs/architecture.md) — pembagian tanggung jawab komponen, alur data, batas model, dan keputusan yang masih perlu difinalisasi.
- [Panduan workspace](docs/WORKSPACE.md) — tata letak repository, pembagian area kerja, dan aturan kerja/commit langsung di `main` sesuai permintaan pemilik repository.
- [Aturan dokumentasi](rules/documentation.md) — sumber rujukan, aturan sinkronisasi, dan kapan mencatat perubahan.
- [Aturan mutu UI](rules/ui.md) — prinsip implementasi dan review UI Flutter.
- [Panduan Flutter](app/README.md) — setup dan penggunaan aplikasi mobile.
- [Panduan backend](server/README.md) — setup dan penggunaan API Node.js.

Jika ada perbedaan antara rekomendasi lama dan pembaruan terbaru, jangan mengubah keputusan diam-diam. Tandai konflik dan pastikan tim menyepakati keputusan sebelum implementasi.
